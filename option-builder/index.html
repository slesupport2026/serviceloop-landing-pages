iHow do I get my API key?
  1. Sign in to Housecall Pro on a computer as an Admin. Office staff logins can't make keys.
  2. Go to My Apps → All Apps and search for API Key Management.
  3. Open it and click Generate API Key.
  4. Name it Option Builder, set Permissions to Full access (Read-only can search but can't send estimates), and click Generate key.
  5. Copy the key and paste it below. Housecall Pro only shows it once.

API keys come with the Housecall Pro MAX plan. If you don't see API Key Management, your plan doesn't include it. To cut this app off later, delete the key in the same place.
